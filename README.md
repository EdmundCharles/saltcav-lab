# Saltcav Lab

Моделирование и визуализация выщелачивания горизонтального соляного канала и полуканала в блоке каменной соли (NaCl).

---

## Возможности

- **Физическая модель сечения ($r(\theta, x)$):**
  - Смешанная конвекция по правилу Черчилля.
  - Ламинарный перенос и вынужденная конвекция (Левек — Грэц).
  - Свободная конвекция: плюмы у потолка ($Sh \sim Ra^{1/3}$), пограничный слой на боковых стенках ($Sh \sim Ra^{1/4}$), подавление конвекции на дне.
  - Плотностное расслоение и гидростатическая устойчивость рассола.
  - Перемещение фронта растворения по схеме Годунова.
  - Учёт двух геометрий: круглый канал в блоке (`channel`) и полуканал у смотрового стекла (`window`).
- **Расчёт на глубине:** гидродинамика подающих и отводящих трубок, сжимаемость и вязкость рассола под давлением, оценка сужения каверны ползучестью соли (BGRa).
- **Интерактивный веб-визуализатор:**
  - Локальный zero-dependency HTTP-сервер на стандартной библиотеке Python.
  - Анимация роста сечения каверны на Canvas 2D в реальном времени.
  - Синхронное отображение продольного профиля, поперечного среза и телеметрии (объём, концентрация, расход).
  - Плеер с регулировкой скорости, шагом по кадрам и интерактивным слайдером.
- **Удобный CLI:** запуск расчетов в консоли, экспорт в CSV и валидация конфигураций.

## Структура проекта

```text
saltcav-lab/
├── configs/               # Примеры конфигураций YAML (channel, window, deep_1200m)
├── docs/                  # Теория и вывод математических формул
├── src/saltcav/
│   ├── core/              # Валидация Pydantic (LabConfig) и свойства рассола (brine)
│   ├── geometry/          # Геометрия круглого канала и произвольного сечения
│   ├── leaching/          # Численные модели растворения (section, axisym, depth)
│   ├── mechanics/         # Закон ползучести BGRa для глубоких пластов
│   ├── web/               # Локальный HTTP-сервер и статика веб-приложения
│   └── cli.py             # Интерфейс командной строки
├── tests/                 # Модульные и верификационные тесты (88 тестов)
├── pyproject.toml         # Конфигурация сборки и минимальные зависимости
└── run_web.py             # Точка быстрого запуска веб-интерфейса
```

## Быстрый старт

### 1. Установка

```bash
# Клонирование и переход в каталог
cd saltcav-lab

# Создание виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка пакета в режиме разработки
pip install -e ".[dev]"
```

Зависимости минимальны и кроссплатформенны:
- `numpy`, `scipy`, `pydantic`, `pyyaml`
- Для тестов: `pytest`

---

### 2. Запуск веб-визуализатора

Самый простой способ:
```bash
python run_web.py
```
или через CLI:
```bash
saltcav web --port 8080
```
После запуска откройте в браузере: **http://127.0.0.1:8080**

---

### 3. Запуск расчётов из командной строки

Проверка конфигурационного файла:
```bash
saltcav check configs/channel.yaml
```

Запуск симуляции с сохранением динамики в CSV:
```bash
saltcav run configs/channel.yaml --out result.csv
```

---

### 4. Использование в Python-скриптах

```python
from saltcav.core.lab_config import load_lab_config
from saltcav.leaching.section import simulate_section

# Загрузка и валидация конфигурации
cfg = load_lab_config("configs/channel.yaml")

# Запуск расчёта
res = simulate_section(cfg)

print(f"Шагов: {len(res.times)}")
print(f"Итоговый объём: {res.volume[-1] * 1e6:.2f} см³")
print(f"Максимальный радиус: {res.radius[-1].max() * 1e3:.2f} мм")
```

---

### 5. Запуск тестов

```bash
pytest tests
```
Все 88 модульных и верификационных тестов проходят за ~3-4 секунды.
